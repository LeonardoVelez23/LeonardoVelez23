> Flutter · Dart · BLoC/Cubit · MVVM · REST APIs · PlaceToPay

Mobile app for Hospital Vozandes patients. Covers medical appointment scheduling, payment gateway integration (PlaceToPay via WebView), medical exam results, billing, and family structure for group bookings. Built for Android & iOS from a single codebase.

*App móvil para pacientes del Hospital Vozandes: agendamiento de citas, pagos con PlaceToPay, resultados de exámenes, facturación y estructura familiar. Multiplataforma (Android & iOS).*
